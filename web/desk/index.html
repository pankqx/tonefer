Instructions

Everything you need to connect your phone and laptop and move notes, photos and files between them. Private, encrypted and offline.

01 First-time setup 02 One-click & auto hotspot 03 Sending and receiving 04 Android app 05 Troubleshooting 06 Privacy and security 07 Transfer speed 08 Windows

01 First-time setup

  1. Connect the two devices. Use one of these:
    • Phone hotspot: phone Settings → Hotspot → on. Then join that network from this laptop.
    • USB tethering (fastest): plug the phone into the laptop and turn on Settings → Hotspot & tethering → USB tethering.
    • Same Wi‑Fi: any network both devices are on also works.
  2. Scan the code. Point the phone camera at the QR code in the Pair a phone window, then open the link. If scanning fails, type the address shown under the code into Chrome.
  3. Keep it handy. In Chrome on the phone, choose ⋮ → Add to Home screen. Or install the Android app (section 04).

You only pair once. The code updates itself if the laptop changes network.

02 One-click everyday use & auto hotspot

Easiest: install the Ubuntu app. Download github.com/pankqx/tonefer/releases/latest/download/tonefer.deb, double-click it, then open Tonefer from your apps. It starts at login, runs in its own window and keeps receiving in the background.

Running from source instead? Run the installer once from the Tonefer folder:

./scripts/install-ubuntu.sh --hotspot "Your Hotspot Name"
  • Tonefer starts in the background whenever you log in.
  • Tonefer appears in your app launcher and opens in its own window.
  • The firewall port is opened once.
  • The laptop joins your phone's hotspot automatically, even when it's on another Wi‑Fi.

Auto-join the hotspot

In the Auto-join hotspot window, pick your phone's hotspot and leave the switch on. Tonefer checks every few seconds. As soon as the hotspot appears, the laptop joins it. Join the hotspot once by hand first so the laptop knows its password.

Daily routine

  1. Share from the phone (Share → Tonefer, Android app).
  2. If the laptop isn't reachable, the app keeps the item and shows Turn on hotspot. One tap opens the hotspot switch.
  3. The laptop joins within seconds and the item is delivered on its own.

Android doesn't let apps switch the hotspot on by themselves (blocked since Android 8). Tonefer takes you straight to the switch and does everything else. The fastest route is the Hotspot tile in the phone's Quick Settings.

To undo the setup: ./scripts/uninstall-ubuntu.sh

04 Android app

The Android app adds what a web page can't:

  • Share → Tonefer from Gallery, Files or any app.
  • Finds the laptop automatically, even when its address changes.
  • Stays connected in the background, with notifications.
  • Options for theme, auto-saving photos, auto-copying notes and image quality.

On the phone, download github.com/pankqx/tonefer-android/releases/latest/download/tonefer.apk, open it, and tap Scan pairing code.

05 Troubleshooting

Phone says "This site can't be reached"
Check that the laptop is on the phone's hotspot (the Pair a phone window shows the network). Then open the firewall: sudo ufw allow 8765/tcp
The QR code opens but nothing loads
Make sure Tonefer is still running on the laptop. Then type the address under the code into Chrome.
The phone shows "Unpaired"
Someone used Unpair all phones. Scan the new code.
Still stuck?
Run ./run.sh doctor in the Tonefer folder. It lists the addresses, the network and any firewall in the way.

07 Transfer speed

The speedometer shows the real speed of each transfer as it happens, measured by the laptop while the bytes cross the network. It isn't an estimate.

  • Phone → laptop and Laptop → phone keep the last real result for each direction.
  • Run speed test sends 16 MB each way between the laptop and the connected phone.
  • Typical speeds: phone hotspot 3–20 MB/s (5 GHz is faster), USB tethering 15–40 MB/s.
  • Very small items finish before the connection reaches full speed, so they aren't counted.

08 Windows

  1. Install Python 3 from python.org (tick Add Python to PATH), then double-click run.bat.
  2. When Windows Firewall asks, allow Private networks.
  3. Join the phone's hotspot once. In Settings → Network & internet → Wi‑Fi → your hotspot, turn on Connect automatically when in range and choose Private network.
  4. Pick the hotspot in the Auto-join hotspot window, so Tonefer switches to it even when the laptop is on another Wi‑Fi.
  5. To start with Windows: press Win+R, type shell:startup, and put a shortcut to run.bat there.

06 Privacy and security

  • Everything stays on your local network. There are no servers, accounts or cloud.
  • Every message and file is end-to-end encrypted (XSalsa20‑Poly1305) with a 256‑bit key shared only by the QR scan.
  • This window only works on this laptop. Other devices can't open it.
  • Unpair all phones changes the key immediately.
